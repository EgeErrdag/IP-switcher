Hemen dene 👇 Nasıl kurarım?

Çok basit anlatalım 🍼

Hiç bilgisayar bilmeyen biri için bile.

🏠

IP adresi = ev adresi

İnternete bağlanan her cihazın bir adresi var. Mektuplar (yani veriler) bu adrese gelir. Buna IP adresi denir. Örnek: 192.168.1.25

📮

DHCP = postacı adres verir

Normalde modem sana kendisi bir adres verir. Sen hiçbir şey yapmazsın. Buna DHCP yani “otomatik” denir.

✍️

Statik IP = adresi sen seçersin

Bazen (iş yerinde, bir cihaza bağlanırken, kamerada, PLC'de…) adresi senin yazman gerekir. Buna statik IP denir.

🔁

Kurulum: 4 adım 🛠️

Sadece Windows 10 / 11'de çalışır.

  1. 1

    Python'u kur

    python.org'dan Python 3.10 veya üstünü indir. Kurarken “Add Python to PATH” kutusunu mutlaka işaretle.

  2. 2

    Projeyi indir

    GitHub'da yeşil Code → Download ZIP de ve bir klasöre çıkar. Ya da:

    git clone https://github.com/EgeErrdag/IP-switcher.git
  3. 3

    Gerekenleri yükle

    Klasörün içinde bir terminal aç ve yaz:

    pip install -r requirements.txt
  4. 4

    Çalıştır

    run.bat dosyasına çift tıkla. Ya da:

    python main.py

    🛡️ Windows “Bu uygulamanın değişiklik yapmasına izin verilsin mi?” diye sorar. Evet de. IP değiştirmek için yönetici izni şart.

Nasıl kullanılır? 📖

Ne yapmak istiyorsan ona tıkla.

  1. 1Adapter listesinden kabloyu (Ethernet) veya Wi-Fi'ı seç.
  2. 2IP Address kutularına istediğin adresi yaz. Ör: 192.168.1.50
  3. 3Subnet genelde 255.255.255.0 olur.
  4. 4Gateway modemin adresidir, genelde 192.168.1.1.
  5. 5DNS boş kalırsa 8.8.8.8 kullanılır.
  6. 6Mor Apply Settings düğmesine bas. Yeşil “Applied successfully” yazısını gör. ✅
  1. 1Adapter'ı seç.
  2. 2Yeşil DHCP Mode düğmesine bas.
  3. 3“Switched to DHCP” yazar. Modem sana yine kendisi adres verir. 🎉

Ne yaptığını bilmiyorsan ve internet gittiyse: DHCP Mode'a bas. Çoğu zaman her şeyi eski haline getirir.

  1. 1Kutulara sık kullandığın ayarları yaz.
  2. 2Sol alttaki + Save Current Config düğmesine bas.
  3. 3Bir isim ver: “Ofis”, “Ev”, “Kamera” gibi.
  4. 4Profil soldaki listede belirir. Bilgisayar kapansa da kaybolmaz.
  1. 1Soldaki listede profili bul.
  2. 2Load düğmesine bas, bilgiler kutulara dolar.
  3. 3Apply Settings ile uygula.
  4. 4Silmek istersen kırmızı x'e bas.

⚠️ Profil sadece IP ve Gateway'i hatırlar. Subnet ve DNS'i yüklemeden önce bir kontrol et.

Sık sorulanlar 🤔

Mac veya Linux'ta çalışır mı?

Hayır. Windows'un kendi netsh aracını kullandığı için sadece Windows 10/11'de çalışır.

Neden yönetici izni istiyor?

Windows, ağ ayarlarının sadece yönetici tarafından değiştirilmesine izin verir. Uygulama açılırken bu izni kendisi ister.

Bilgisayarı bozar mı?

Hayır. Sadece ağ adresini değiştirir. Bir sorun olursa DHCP Mode ile otomatiğe dönersin.

İnternetim gitti, ne yapayım?

Büyük ihtimalle yanlış Gateway veya IP yazdın. DHCP Mode'a bas, internet geri gelir.

Profillerim nerede saklanıyor?

Uygulamanın klasöründeki saved_ips.json dosyasında. Bu dosyayı kopyalarsan profillerin de taşınır.

Ekran 5 saniyede bir değişiyor, normal mi?

Evet. Uygulama her 5 saniyede bir güncel IP'ni kontrol edip gösterir.
